Tax & 990 Alignment Search

Search through nonprofit award data joined to IRS 990 filings. Data includes aggregated 990 information (EIN, mission statement, programs) alongside government award amounts and textual AI-based alignment analysis.

How it works

By default, each typed word is matched exactly. If you check "Enable prefix search," then any words that start with your search terms will also match. All keywords are combined with AND logic, so all words must match to see results.

For performance reasons, only the first 100 matching rows are displayed. Partial matches are only included if the prefix option is enabled.

You can search by EIN (e.g., 59-0936101), UEI (e.g., U5MMBAC9XAM5), or general keywords from the award descriptions or 990 text.
