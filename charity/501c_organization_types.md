# 501(c) Organization Types: Long Descriptions

| Type       | Purpose                                                                 | Key Restrictions                                                                 |
|------------|-------------------------------------------------------------------------|----------------------------------------------------------------------------------|
| 501(c)(1)  | Corporations organized under an Act of Congress (e.g., Federal Credit Unions, Federal Reserve Banks). Serve public purposes like banking or housing. | No IRS filing required (created by Congress). Contributions deductible only for public purposes. No private inurement. |
| 501(c)(2)  | Title-holding corporations for exempt organizations. Hold property and turn over income (less expenses) to a tax-exempt parent organization. | Income must be paid to exempt parent. Limited to property management. No private benefit. |
| 501(c)(3)  | Charitable, religious, educational, scientific, literary organizations, or those testing for public safety, fostering amateur sports, or preventing cruelty to children/animals. Includes public charities (e.g., CHAI) and private foundations. | No private inurement. No substantial lobbying (501(h) election allows limited lobbying). No political campaign activity. File Form 1023/1023-EZ. Contributions tax-deductible. |
| 501(c)(4)  | Civic leagues or social welfare organizations promoting community welfare (e.g., homeowners associations, volunteer fire companies). | No private inurement. Unlimited lobbying if related to purpose. Contributions not tax-deductible unless for specific purposes (e.g., fire departments). File Form 1024. |
| 501(c)(5)  | Labor, agricultural, or horticultural organizations (e.g., unions, farm bureaus). Promote worker rights or agricultural interests. | No private inurement. Lobbying allowed if related to purpose. Contributions not deductible. File Form 1024. |
| 501(c)(6)  | Business leagues, chambers of commerce, or professional associations (e.g., American Solar Grazing Association). Improve business conditions. | No private inurement. Unlimited lobbying for business interests. Contributions deductible as business expenses. File Form 1024. |
| 501(c)(7)  | Social or recreational clubs (e.g., country clubs, fraternities). Provide leisure activities for members. | Non-discriminatory policy (except religion). Minimal public use (<$2,500/year or <5% receipts). Contributions not deductible. File Form 1024. |
| 501(c)(8)  | Fraternal beneficiary societies operating under a lodge system, providing life, sickness, or other benefits (e.g., Elks). | Must offer insurance/benefits. Non-discriminatory except for religion. Contributions not deductible. File Form 1024. |
| 501(c)(9)  | Voluntary employees’ beneficiary associations providing life, sickness, or accident benefits to members (e.g., labor union benefits). | Membership voluntary, tied to employer/union. No discrimination in benefits. Contributions not deductible. File Form 1024. |
| 501(c)(10) | Domestic fraternal societies without insurance, devoting earnings to charitable, religious, or educational purposes (e.g., Masons). | No insurance benefits. Funds for exempt purposes. Contributions not deductible. File Form 1024. |
| 501(c)(11) | Teachers’ retirement fund associations. Pay retirement benefits to local teachers/school employees. | Funded by taxes, donations, investments. Local scope. Contributions not deductible. File Form 1024. |
| 501(c)(12) | Local benevolent life insurance associations, mutual irrigation, or telephone companies. Serve members’ needs. | 85%+ income from members for losses/expenses. Contributions not deductible. File Form 1024. |
| 501(c)(13) | Cemetery companies operated for members or charitable purposes. | No private profit. Funds for maintenance. Contributions deductible if charitable. File Form 1024. |
| 501(c)(14) | State-chartered credit unions or mutual reserve funds. Provide financial services to members. | State-regulated. No private inurement. Contributions not deductible. File Form 1024. |
| 501(c)(15) | Mutual insurance companies or associations (small insurers). Provide insurance to members. | Gross receipts <$500,000. Contributions not deductible. File Form 1024. |
| 501(c)(16) | Cooperative organizations financing crop operations. Support agricultural activities. | Funds for crop financing. No private profit. Contributions not deductible. File Form 1024. |
| 501(c)(17) | Supplemental unemployment benefit trusts. Pay benefits to employees during layoffs. | Benefits only for involuntary layoffs. No private inurement. Contributions not deductible. File Form 1024. |
| 501(c)(18) | Employee-funded pension trusts (pre-1959). Provide pension benefits. | Employee-funded only. No diversion of funds. Contributions not deductible. File Form 1024. |
| 501(c)(19) | Veterans’ organizations providing benefits or social activities for members. | 75%+ members are veterans. Contributions deductible if 90%+ for exempt purposes. File Form 1024. |
| 501(c)(20) | Group legal services organizations (discontinued after 1992). Provided legal benefits. | Obsolete. No new exemptions. |
| 501(c)(21) | Black lung benefit trusts. Fund benefits for coal miners. | Specific to black lung claims. Contributions deductible. File Form 1024. |
| 501(c)(22) | Withdrawal liability payment funds. Manage employer pension liabilities. | Specific to pension plans. No private inurement. Contributions not deductible. File Form 1024. |
| 501(c)(23) | Veterans’ organizations (pre-1880, benefits-focused). Similar to 501(c)(19) but older. | Rare. Contributions deductible if for exempt purposes. File Form 1024. |
| 501(c)(24) | Trusts for ERISA Section 4049 plans (post-1980 groundwork for organizations with significant grants or foreign expenses. | Specific to ERISA plans. No private inurement. Contributions not deductible. |
| 501(c)(25) | Title-holding corporations with multiple parents. Hold property for exempt orgs. | Up to 35 parents. Income to exempt orgs. No private benefit. File Form 1024. |
| 501(c)(26) | State-sponsored high-risk health insurance organizations. Provide coverage to high-risk individuals. | State-regulated. No private profit. Contributions not deductible. File Form 1024. |
| 501(c)(27) | State-sponsored workers’ compensation reinsurance organizations. Manage insurance risks. | State-regulated. No private inurement. Contributions not deductible. File Form 1024. |
| 501(c)(28) | National Railroad Retirement Investment Trust. Manage railroad retirement funds. | Specific to railroad pensions. No private benefit. Contributions not deductible. |
| 501(c)(29) | CO-OP health insurance issuers under ACA. Provide consumer-oriented health plans. | ACA-specific. No private profit. Contributions not deductible. File Form 1024. |

Notes:
- 501(c)(3) is most relevant to your analysis (e.g., CHAI), covering charities with strict rules against private benefit, political activity, and excessive lobbying.
- 501(c)(4) and 501(c)(6) may appear in your TSVs for advocacy or business-focused NGOs, with fewer restrictions on lobbying.
- Descriptions are sourced from IRS Publication 557 and web references, ensuring accuracy for your nonprofit transparency campaign.
